Decided (J. Lecy, 2026-09-27/28) and applied

  • Part III programs (fix 10). The shared variable names across the program tables are intentional: the tables are parsed separately and stacked later. This is recorded as an R07 exception, and collisions are now checked within each table. Inspection found no within-table collisions, the one-row program tables never repeat within a filing, and coverage runs continuously from 2009 to 2024 across the 2013 schema change.
  • Schedule O (fix 10). SO-T99-SUPPLEMENTAL-INFO is renamed SO-P00-T99-SUPPLEMENTAL-INFO.
  • List-valued fields (fixes 10, 13, 14). A new variables.csv column, multi_value, marks fields whose repeated values are joined into one cell. It is set for:
    • states licensed for fundraising, and gaming states;
    • states where the return is filed (990 and 990-PF);
    • foreign financial-account countries (990 and 990-PF);
    • 990-EZ foreign office countries;
    • special conditions;
    • 990-PF contributing and shareholder managers.
  • 501(c) subsection, TY2009 (fix 10). From the 2009v1.0 schema: a 501(c)(3) filer checked Organization501c with the attribute typeOf501cOrganization = 3. The new variable F9_00_EXEMPT_STAT_501C_TYPE maps that attribute, and organization501cTypeTxt from 2013. A production rule derives the 2009 501(c)(3) flag.
  • TY2012 checkbox (fix 10). OtherExplainInSchO is the "Other (explain in Schedule O)" box of Part VI line 18. This comes from its position in TY2012 filings and its 2013 successor OtherInd. It now maps to F9_06_DISCLOSURE_AVBL_OTH_X.
  • 990-PF merge (fixes 11–15).
    • Source: F990-PF-FULL.xlsx, merged as form F990PF. The shared header uses the same F9_00_ variables.
    • Attachments filed with every form map per form (xpath_forms.csv), and the build writes concordance-990pf.csv for the separate PF database.
    • The 11 rows without a variable now have variables.
    • With the workbook's names, none of the 34 PF collision errors in issues.html remain.
    • The rest of the PF review, with 2023 schema line numbers, added the 2023 qualifying distributions, the section 4960 tax and the unredacted 990-PF Schedule B, and fixed the table cardinalities.
  • 990-PF Part IX-A, direct charitable activities (fix 16). The schemas allow at most four activities (Part VIII-A from 2023), each slot its own element, with no repeating "other" group. The four slots are now PF_09_CHARIT_ACT_DESC_1–_4 and PF_09_CHARIT_ACT_EXP_1–_4, in wide format in the one-row table PF-P09-T01-CHARITABLE-ACTIVITIES. Before, one description and one expense variable in a table marked MANY received up to four values per filing. In TY2023, slot 1 is filled by 32,488 foundations and slots 2–4 by 7,668, 4,769 and 3,257.
  • Schedule B contributor number (fix 17). SB_01_CONTRIBUTOR_TYPE, which holds the Part I contributor number, is renamed SB_01_CONTRIBUTOR_NUM, matching SB_02_NONCASH_CONTRIBUTOR_NUM and SB_03_CONTRIBUTOR_NUM. The contributor type is the person/payroll/noncash checkboxes.
