1. 990-PF Part IX-A: four activity slots in one variable

Cases: PF_09_CHARIT_ACT_DESC, PF_09_CHARIT_ACT_EXP (table PF-P09-T01-CHARITABLE-ACTIVITIES).

Form 990-PF Part IX-A, "Summary of Direct Charitable Activities" (Part VIII-A from the 2023 redesign). The schemas show:

  • It is a hard limit of four activities, with no catch-all. The group (SummaryOfDirectCharitableActy in 2009–2012, SummaryOfDirectChrtblActyGrp from 2013) occurs at most once per return. It holds exactly four numbered slot pairs: Description1–4 and Expenses1–4 (2009v1.0), later Description1Txt–4Txt and Expenses1Amt–4Amt (2023v5.0). There is no "other activities" element and no many-row case, unlike Form 990 Part III, where line 4d "other program services" repeats without limit.
  • Each slot has its own xpath. In TY2023 filings slot 1 is used by 32,488 foundations and slots 2–4 by 7,668, 4,769 and 3,257. No slot repeats within a filing.
  • The v1 PF concordance maps all four slots to one description variable and one expense variable in a table marked MANY. Because the slots are sibling elements, not repeated rows, a parser gets up to four values for one cell in a single row.
  1. Four variables per column (PF_09_CHARIT_ACT_DESC_1–_4 and PF_09_CHARIT_ACT_EXP_1–_4) in a one-row table. This is how Part IX-B program-related investments is already mapped (DESC_1, DESC_2, AMT_1–AMT_3).
  2. Four one-row tables sharing variable names, stacked later, like the 990 Part III programs.

Recommendation: option 1. The Part III approach answers a mix of one-row programs (4a–4c) and a many-row "other" group, which Part IX-A does not have. A fixed four-slot line is a plain one-row table, and stacking into long form can still be done downstream from the _1–_4 suffixes.

2. Rename SB_01_CONTRIBUTOR_TYPE?

The variable holds the contributor number (ContributorNum) of Schedule B Part I, not a contributor type. The type is the person/payroll/noncash checkboxes added in fix 14. Renaming it SB_01_CONTRIBUTOR_NUM would match the new SB_02_NONCASH_CONTRIBUTOR_NUM and SB_03_CONTRIBUTOR_NUM, but it changes a column name downstream.
