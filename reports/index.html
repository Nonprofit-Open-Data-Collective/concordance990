How to read these reports

Each report checks one concordance variable against how its xpaths are actually used in e-filed returns: which xpaths carry values in which years, whether the values look like the variable’s data type, and whether pooled xpaths agree. Errors are likely mapping mistakes; warnings need a reviewer’s judgement; info lines are context.
