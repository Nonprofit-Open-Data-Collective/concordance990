# concordance990: IRS 990 E-File Master Concordance

The Master Concordance maps xpaths in IRS Form 990 e-file XML returns
onto a documented set of research variables and relational tables. This
package holds the concordance as component tables (forms, parts, tables,
variables, xpaths), builds the unified tidy concordance from them, and
provides tools to validate it against filing evidence and to document
every change from version 1.
