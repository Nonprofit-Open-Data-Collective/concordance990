# concordance.csv: the full concordance

The full Master Concordance, one row per xpath, for all forms and
schedules (990, 990-EZ, 990-PF and Schedules A to R), in the v1 column
layout. This page is built from the package with `concordance("v1")`,
the same call that writes `concordance.csv` at the root of the
[repository](https://github.com/Nonprofit-Open-Data-Collective/concordance990),
so the table and the download always match the package. The 990-PF
database on its own is
[concordance-990pf.csv](https://nonprofit-open-data-collective.github.io/concordance990/articles/concordance-990pf-csv.md).

The columns are described in [The component
tables](https://nonprofit-open-data-collective.github.io/concordance990/articles/table-structure.md)
and each variable in the [data
dictionaries](https://nonprofit-open-data-collective.github.io/concordance990/articles/data-dictionary-990.md).
R users can skip the file:
[`concordance990::concordance()`](https://nonprofit-open-data-collective.github.io/concordance990/reference/concordance.md)
returns the same table.

**Using the table.** Search matches any of the 24 columns, and the chips
filter by form. Click a label to see the other columns of that xpath.
Click a variable name to open its validation page. *Download matching
rows* saves only the rows that match the search and filter.
