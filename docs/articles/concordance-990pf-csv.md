# concordance-990pf.csv: the 990-PF database

The concordance of the **990-PF research database**: the Form 990-PF
xpaths, the return header shared with the 990 and Schedule B, with the
990-PF mappings of shared xpaths, in the v1 column layout. This page is
built from the package with `concordance("v1", form = "F990PF")`, the
same call that writes `concordance-990pf.csv` at the root of the
[repository](https://github.com/Nonprofit-Open-Data-Collective/concordance990),
so the table and the download always match the package. The full
concordance is
[concordance.csv](https://nonprofit-open-data-collective.github.io/concordance990/articles/concordance-csv.md).

The variables are described in the [990-PF data
dictionary](https://nonprofit-open-data-collective.github.io/concordance990/articles/data-dictionary-990pf.md).
R users can skip the file:
`concordance990::concordance(form = "F990PF")` returns the same table.

**Using the table.** Search matches any of the 24 columns, and the chips
filter by form. Click a label to see the other columns of that xpath.
Click a variable name to open its validation page. *Download matching
rows* saves only the rows that match the search and filter.
